# 1.2.1 — release preparation

**Not published.** The version number is approved; macOS and Windows packages are being prepared. No release, tag, announcement or merge is authorized by this preparation.

## Changes

- A completed Snorca slice updates the status icon and menu instead of opening the dashboard.
- On macOS, the native menu opens automatically after slicing or reslicing, and Tracker runs without a Dock icon. Dismiss the menu with Escape or a click outside it. Open the dashboard explicitly from the menu.
- The menu identifies the latest completed plate and its timestamp. Used heads have green checks or red crosses, with the estimated remaining amount or deficit including reserve. Unused heads stay neutral. Missing evidence has a neutral overall status.
- Balance and reserve changes refresh the result without reopening the menu.
- Forecast menu text is translated into English, Russian, German, Ukrainian and Spanish.
- Opening the forecast from the menu selects the latest plate and avoids blocking the macOS GUI thread.

## Data and scope

This update keeps the 1.2 beta data directory `SnapmakerSpoolTracker-Beta12`, schema 4 and loopback port 8766. Existing beta inventory is retained; there is no automatic import from Menu Test 1/2 or older stable installations. Back up before replacing an installed app. Preparing these packages does not install them or access a printer.

Forecasts remain estimates for one completed plate, using the explicitly assumed mapping material 1→T0 … 4→T3. Slicing does not reserve or deduct filament and does not start printing. No RFID, Spoolman or firmware changes are included; Tracker continues to target original U1 firmware.

## Validation and remaining limitations

- Viktor confirmed Menu Test 2 on macOS: automatic menu opening after slicing, no dashboard popup, correct translations. Earlier testing covered one-color and multi-color sufficient/insufficient forecasts.
- Isolated native macOS checks covered slice/reslice menu opening, hidden dashboard, accessory application policy and no reopening on a balance change.
- Source suite before version preparation: 435 passed, 4 skipped. Final package/CI evidence is delivered beside the artifacts.
- **Windows GUI, real Snorca slicing and earlier automatic-window behavior on Windows remain unverified.** In 1.2.1, Windows gets tray status/menu updates, not macOS-only automatic menu opening.
- macOS package is Apple Silicon arm64, ad-hoc signed and not notarized. Windows package is x64 and needs WebView2 for its window.

Prepared packages include SHA256 files and per-platform BUILD-INFO JSON recording the source commit, tree and artifact hash. None of these files is a published release.
