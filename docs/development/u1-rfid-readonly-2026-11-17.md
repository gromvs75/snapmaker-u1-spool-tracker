## Сопоставление с модулем и стендом

В `dev/klipper/tracker_uid.py` для `2.1.0.157` разрешён точный SHA-256:

```text

```

Хеш фактического файла
`/home/lava/klipper/klippy/extras/fm175xx_reader.py` получен и совпал.
Номер прошивки сам по себе недостаточен: файл мог быть изменён независимо.
Кроме хеша модуль при подключении проверяет загруженные методы и конфликты
обёрток. Сейчас модуль не запускался, поэтому эта проверка на U1 не выполнена.

Модуль наблюдает результаты штатного RFID-драйвера через обёртки в памяти,
сохраняя штатные callbacks. Он не добавляет принудительное сканирование и не
заменяет файл драйвера. Стендовые результаты предыдущего этапа:
986 passed / 3 skipped общей регрессии, 250 профильных тестов,
17 процессных проверок экспортированного пакета. Это **прежние стендовые
результаты**, не испытание физических RFID-антенн данного U1.
См. [отчёт стенда](rfid-installation-2026-11-17.md).

Код приложения и модуля в этом диагностическом этапе не менялся; повторный
прогон тестов не выполнялся. Пакет `0.2.0-bench` остаётся предназначенным только
для маркированных остановленных симуляторов. Использовать его для записи на U1
или обходить ограничение маркером нельзя.
