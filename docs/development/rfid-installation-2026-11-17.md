## Что изменено

Логика из прежнего `dev/labs/uid_module_bench/install.py` перенесена в
`scripts/rfid_module_tool.py`; прежний импорт оставлен совместимым для стендов.
Инструмент использует только стандартную библиотеку Python и POSIX-блокировку.

- `inspect` и `plan` работают без записи. План перечисляет три целевых файла,
  исходные/новые хеши и привязку к корню, драйверу, модулю и дереву include.
  CLI требует ранее сохранённый неизменённый план; устаревший план отклоняется.
- Точная проверка хеша штатного драйвера. Сам файл драйвера никогда не меняется.
  Проверка выполняется также при повторной установке и между записями файлов.
- Вложенные include проверяются до установки: существующие секции модуля,
  дублирующий wildcard include, циклы, отсутствующие обязательные файлы и выход
  за поддерживаемый каталог блокируют установку. Симлинки/жёсткие ссылки запрещены.
- Перед записью сохраняется отдельная копия с уникальным ID и правами 0600.
  Копия не перезаписывается следующими установками. Журнал проверяется по копии,
  её хешу, схеме и фиксированному списку целевых файлов.
- Откат сначала проверяет весь набор. Он удаляет точный include-блок, сохраняя
  посторонние поздние изменения основного конфига. Для прерывания самого отката
  сохраняется отдельный план восстановления; повтор продолжает оставшиеся шаги.
- Повреждённая копия/журнал, чужое изменение модуля или конкурентная правка не
  приводят к молчаливому перезаписыванию. При неразрешимом конфликте файлы остаются
  для ручного разбора. Схема старого журнала v1 не конвертируется автоматически.
- Архив содержит CLI, неизменённый `tracker_uid.py` (версия API-модуля остаётся
  `0.1.0-bench`), инструкции RU/EN и манифест. CLI проверяет хеши содержимого
  архива перед работой. Манифест не является цифровой подписью.

Текущий модуль наблюдает штатный драйвер через обёртки в памяти; его защита
от неизвестного исходника, изменённого загруженного метода и чужой обёртки
сохранена. Откат файлов выполняется при остановленном процессе; новый запуск
Klipper необходим для удаления перехватчиков из памяти.

## Что остаётся перед реальным U1

Нужны отдельное разрешение, проверка фактического драйвера/путей, полноценная
проверка остановки и восстановления службы и независимый путь аварийного отката.
Маркер и файл `.klipper-running` — договорённость стенда, не доказательство
состояния реального сервиса. Обходить это ограничение нельзя. Физическое радио,
антенны и настоящие метки пока не проверены. Автодозаправка и её действующие
ограничения этим этапом не изменялись.
