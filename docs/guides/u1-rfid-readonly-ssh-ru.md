# U1: сверка RFID-драйвера через SSH — только чтение

Инструкция подготовлена 17.11.2026 для диагностированного U1 с Klipper
`2.1.0.157_20261028045538`. Она не устанавливает RFID-модуль и не меняет
конфигурацию или состояние печати.

## Что уже установлено

По адресу `192.168.2.133:22` SSH уже отвечает. Повторно включать Root Access,
Advanced Mode, менять прошивку или перезапускать принтер **не требуется для
этой проверки**. Если адрес устройства изменился, сначала уточните его на
экране принтера; приведённый ниже отпечаток относится к наблюдению 17.11.2026.

Предыдущий отказ `Host key verification failed` означал, что на Mac не было
сохранённого доверенного ключа U1, а команда запрещала принимать неизвестный
ключ. Пароль и чтение файла до этого этапа не проверялись.

Документация проекта Extended Firmware описывает штатный доступ через меню
`Settings → Maintenance → Root Access` начиная с 1.2.0 и учётные записи
`lava` / `root` с заводским паролем `snapmaker`. Здесь используем `lava`.
Это сведения из документации разработчиков сторонней прошивки, а не результат
успешной авторизации на вашем U1. Наличие SSH на вашем устройстве проверено
непосредственно; неизменность заводского пароля пока не проверена.
[Источник](https://github.com/paxx12-snapmaker-u1/SnapmakerU1-Extended-Firmware/blob/develop/docs/ssh_access.md).

Веб-страница `/firmware-config/` относится к Extended Firmware; она не является
обязательным шагом для штатной прошивки. Старые инструкции с патчем прошивки
или включением debug через запись разделов для этой диагностики не нужны.

## Действия на Mac

1. Откройте **Терминал** на Mac. Проверьте, что IP на экране вашего U1 —
   `192.168.2.133`, а Mac находится в вашей локальной сети.
2. Вставьте целиком одну команду:

```sh
ssh -T -o StrictHostKeyChecking=ask -o HostKeyAlgorithms=ssh-ed25519 -o ConnectTimeout=5 -o PreferredAuthentications=password -o NumberOfPasswordPrompts=1 -o ForwardAgent=no -o ClearAllForwardings=yes lava@192.168.2.133 'sha256sum /home/lava/klipper/klippy/extras/fm175xx_reader.py'
```

3. При первом подключении SSH может спросить, доверять ли ключу устройства.
   Наблюдавшийся открытый ключ ED25519 имеет отпечаток:

```text
SHA256:yF7qsimmAVl00osyZLS178ojYkX4/1ywhKLexaYkwq8
```

   Если адрес вашего принтера и отпечаток совпадают, вы можете принять первое
   подключение, введя `yes`. Это сохранит ключ **на Mac**, не на принтере.
   Отпечаток получен по той же локальной сети и не проверен независимым каналом:
   его совпадение позволяет заметить смену ключа относительно нашего наблюдения,
   но само по себе не является независимым доказательством подлинности устройства.
   При другом отпечатке или сообщении `REMOTE HOST IDENTIFICATION HAS CHANGED`
   остановитесь; не удаляйте старый ключ и не отключайте проверку.
4. На запрос `lava@192.168.2.133's password:` введите пароль в Терминале.
   Если заводской пароль не меняли, документированное значение — `snapmaker`.
   Символы при вводе не отображаются — это нормально. Нажмите Enter.
   Изменённый пароль вводите только локально, не присылайте его в чат.
5. Команда выведет хеш и путь, затем сама завершит соединение. Пришлите только
   эту строку либо текст ошибки. Пароль и приватные ключи для сверки не нужны.

Команда создаёт неинтерактивный сеанс без терминала и выполняет только
`sha256sum` для одного файла. Она не импортирует драйвер, не запускает радио,
не вызывает G-code и не управляет службами. Сам SSH-сервер может записать
обычную запись о подключении в свой системный журнал.

## Какой результат ожидается

Для проверенного стендового снимка `2.1.0.157`:

```text
ce7363f8b512e5474d18bd57cdf0660e6e2df57dc256e22f743b3b28c1b70be8  /home/lava/klipper/klippy/extras/fm175xx_reader.py
```

Совпадение означает побайтовое соответствие файла проверенному снимку. Это
ещё не проверка физических меток, антенн или конфликтов загруженных методов.
Другой хеш — повод отдельно разобрать исходник, не добавлять его автоматически
в список разрешённых и не устанавливать модуль наугад.

## Если команда не выполнилась

| Сообщение | Что делать в рамках проверки только чтением |
| --- | --- |
| `Permission denied` | Пароль/вход `lava` не подтверждены. Прислать ошибку; не перебирать пароли и не менять учётные записи |
| `Connection refused` / timeout | Проверить IP и сеть. Не включать службы и не перезапускать принтер в рамках этой инструкции |
| `No such file or directory` | Прислать сообщение: фактический путь нужно уточнить чтением |
| `sha256sum: not found` | Прислать сообщение; не устанавливать пакеты ради проверки |
| Предупреждение о другом ключе | Остановиться и выяснить причину; не использовать `StrictHostKeyChecking=no` |

Установка и перезапуск требуют отдельного разрешения и подготовленного плана
отката. Текущий пакет `0.2.0-bench` предназначен только для стенда.
