# Tracker 1.3.1 — completed-print forecast fix

Released 2026-11-07. Packages: macOS Apple Silicon (arm64) and Windows x64.

## Fix

After a print finished and its consumption was accounted for, the head cards could show the old slice forecast again. The “After printing” figure then subtracted the same planned usage from the updated balance, making it look as though accounting had not finished.

Version 1.3.1 removes the matching old forecast after accounting and restores the head cards to their current inventory balances and material labels. Planned grams, forecast checkmarks and “After printing” captions no longer remain for that accounted slice. Matching uses G-code content and slice time, not color, filename or equal usage amounts. Other models' forecasts remain available.

This fixes the display; it does not apply a second deduction or change the accounting algorithm.

## Validation

- Local U1 simulator and browser regression tests cover completion, a single inventory deduction, forecast removal, repeated polling, observer restart and a different model with the same planned usage.
- The fix was confirmed by a user on a real U1 with the macOS build and local inventory: T3 started at 1000 g, the completed print accounted for 44.65 g, and the card showed 955.35 g with the old forecast removed. T0–T2 balances stayed unchanged.
- GitHub Actions runs tests and builds both desktop packages; attached BUILD-INFO files identify their exact source and checksums.

**Windows GUI and real Snorca slicing on Windows remain unverified.** The real-print confirmation above does not validate physical U1 printing with Spoolman. That integration and long-running operation retain the limitations documented for 1.3.0. macOS is ad-hoc signed, not notarized.

## Upgrade

Export a JSON backup and quit the old Tracker before replacing it. Version 1.3.1 keeps the same inventory directory, settings and data format as 1.3.0. Do not run both versions for the same printer.

If your Snorca post-processing command contains a versioned application filename, update it to the 1.3.1 path. See the [English guide](../guides/en.md) or [Russian guide](../guides/ru.md).

## По-русски

Исправлено повторное появление прогноза уже завершённой и учтённой печати на карточках головок. Теперь показывается текущий остаток катушки; плановый расход, галочка прогноза и строка «После печати» для этой нарезки исчезают. Повторного списания нет — изменено отображение, а не алгоритм учёта.

Исправление проверено на симуляторе, в браузере и пользователем на настоящем U1 с Mac: 1000 − 44,65 = 955,35 г на T3, остальные остатки не изменились. Настройки и данные катушек сохраняются при обновлении. Перед заменой приложения сделайте JSON-backup и закройте старую версию. Если путь в постобработке Snorca содержит номер версии, обновите его.

Windows GUI и настоящая нарезка Snorca на Windows остаются непроверенными. Проверка этой печати не является проверкой реального U1 со Spoolman.
