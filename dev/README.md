# Development tools and isolated labs

- [`labs/`](labs/) — forecast/observer windows and experimental sender apps; run with `python -m dev.labs.<module>` after the editable install.
- [`sample_gcodes/`](sample_gcodes/) — artificial test files.
- [`windows_slice_check/`](windows_slice_check/README_RU.md) — offline Windows test-kit scripts; the Windows GUI scenario has **not** been executed here.
- [`README_MOCK_U1.md`](README_MOCK_U1.md) — loopback printer simulator.
- [`orca_integration/`](orca_integration/README_RU.md) — archived experimental slicer adapter, not required by the 1.2 forecast.

Use temporary stores and test endpoints. These tools are not instructions to connect a physical printer. Build and test commands are in the [developer guide](../docs/development.md).
