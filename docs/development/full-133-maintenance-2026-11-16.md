| Языки | Сохранены RU/EN/DE/UK/ES; основные новые элементы переведены на пять языков | Переключение и сохранение языка в браузерном сценарии | Прежние неполные переводы вложенных элементов и сообщения ядра не объявляются полностью переведёнными |

Параметры применяются к снимкам будущих заданий. Сохранённые планы, ранее
списанные количества и история не пересчитываются. Изменение параметров не может
назначить произвольный UID или подтвердить физическую ручную привязку.

Архивирование не удаляет катушку и не отправляет команду архивирования в Spoolman.
Это локальная организация библиотеки Tracker. Перед архивированием катушка должна
быть снята со всех принтеров, включая неподтверждённые старые назначения; не должно
оставаться незавершённого задания, замены или удалённой операции. При повторном
появлении UID архивной катушки требуется вернуть её в библиотеку. Назначение
архивной нетегированной катушки и её регистрация под новой меткой блокируются
ядром, а не только интерфейсом.

Статистика вычисляется по целым миллиграммам фактических `uid_debits`, включая
уже учтённую часть прерванной печати. Основание берётся из события соответствующего
списания: позднее ручное подтверждение остатка не превращает весь предыдущий
расход в ручной. Расход Spoolman не прибавляется к локальному повторно. Если
ручная операция или замена не позволяет доказать головку, расход показан отдельно.
Округление до 0,1 г применяется только при выводе.

## Резервные копии

Используется существующий конверт 2.0: SQLite, контрольная сумма, версия формата,
проверка схемы, `integrity_check` и внешних ключей. Старый JSON формата 1.3.3 не
выдаётся за копию 2.0; его миграция остаётся отдельной процедурой.

В браузере экспорт скачивает JSON, импорт предлагает файл. В нативном запуске
подключён файловый мост: путь выбирается системным диалогом, JavaScript не может
передать произвольный путь. Отмена диалога не меняет данные. На стенде этот мост
проверен с подставным диалогом и реальными временными файлами, включая HTTP-маршрут.
Это не фактическая проверка окон Save/Open на macOS или Windows.

Перед восстановлением необходимо остановить подключения. После проверки копии
показано количество катушек, заданий, дебетов и операций Spoolman. Новый файл
сбрасывает проверку и подтверждение. Изменение базы после проверки отклоняет
восстановление. Перед заменой создаётся локальная `before-restore-*.json`.
После восстановления подключения остаются остановленными, назначения требуют
проверки, старые неокончательные отправки становятся неопределёнными. Обновление
интерфейса не инициирует запрос к Spoolman.

Исходный коммит проверен отдельно через `git archive` в `/tmp`, без доступа к
рабочей базе: **848 passed, 3 skipped**, 131,32 с. Первый запуск внутри системной
песочницы не смог открыть loopback-сокеты/Chromium; его ошибки не считаются
регрессиями приложения. Прогон исходного коммита вне этих ограничений прошёл.

Промежуточная полная регрессия: **852 passed, 3 skipped**, 110,26 с.
Окончательная полная регрессия: **854 passed, 3 skipped**, 110,23 с.

**6 passed**, 2,77 с. `git diff --check` — без ошибок.

На двух процессных Klipper/Moonraker без аппаратуры: **12 из 12 проверок**.
Сохранены два списания по **2983 мг**. Повтор истории, перезапуск Moonraker A
при работающем B, переподключение и восстановление через GUI не добавили дебетов.
У дополнительной архивной катушки сохранились 125259 мг и параметры 1,751 мм /
1,244 г/см³. Статистика выбранного принтера показала его собственные 2983 мг.
Supervisor остановил все свои процессы: `stopped: true`, `cleanup_errors: []`.

В отдельном сценарии локального Spoolman двойника после экспорта копии расход
был отправлен один раз; затем GUI восстановил старую копию. Остался один локальный

После перезапуска сохранены архив, параметры, UID, язык и очередь. Повреждённая
копия отклонена без замены текущей базы.

Первый новый тест статистики ошибочно запрашивал T0 на втором принтере, где
фикстура содержит UID на T1. Исправлены данные теста; ограничение ядра сохранено.

## Ограничения следующего этапа

Основной launcher пока не переключён на `/desktop`, новая упаковка не собрана.
Нужно закончить проверку остальных функций полной оболочки, включая режим
проверки старта/паузу, затем проверить именно упакованное приложение: ресурсы,
диалоги, трей, второй экземпляр и полный выход. Статус Windows GUI этим этапом
не повышается. Это не завершение всей подготовки пользовательской 2.0.0.

Исследование автодозаправки T3 → T1, допуски и правила автоматического списания
не менялись. Реальный принтер, установленный Tracker, пользовательские базы и
рабочий Spoolman не использовались. Отправки ветки, публикации и объединения с
основной веткой не было.
