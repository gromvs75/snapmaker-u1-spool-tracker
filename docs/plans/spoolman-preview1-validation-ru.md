# Spoolman Preview 1: результаты проверки

Дата: 2026-11-05. Ветка: `spoolman-integration`.
Исходники сборок: `13c9bcc59cc7c0b64c7ebfdfbc5d266cc81a433e`.
Это отдельный Preview, не опубликованный релиз. Номер следующего релиза не назначен.

## Выполнено

- Необязательный каталог Spoolman, привязка катушек T0–T3, прогноз Snorca со свежими остатками.
- Режим только чтения и режим единственного отправителя расхода.
- Устойчивая очередь; неоднозначный результат останавливает отправку до сверки.
- Защита от повторной обработки событий и воспроизведения очереди из backup.
- Отдельные имя приложения, каталог данных и порт 8771; монитор принтера по умолчанию выключен.
- Поддержка оригинальной прошивки U1; алгоритм оценки расхода не изменён.

## Проверки

- Полный локальный набор: **465 passed, 3 skipped**. Пропущенные тесты не считаются проверенными.
- Изолированный настоящий Spoolman **0.27.1**: **22 проверки пройдены**, включая нормальное списание из Tracker и восстановление backup без повторной отправки.
- [macOS CI](https://github.com/gromvs75/snapmaker-u1-spool-tracker/actions/runs/42024343611): успешно.
- [Windows CI](https://github.com/gromvs75/snapmaker-u1-spool-tracker/actions/runs/42024343612): успешно.
- Скачанные архивы: SHA-256 совпадают с файлами контрольных сумм; BUILD-INFO указывает чистое дерево указанного коммита.
- Готовое Mac-приложение arm64: `--self-test` и `codesign --verify --deep --strict` завершились успешно. Подпись ad-hoc, не нотариализация.
- Настройки и назначение катушки проверены в браузере на искусственном каталоге. [Отчёт по интерфейсу Lazyweb](https://www.lazyweb.com/report/lazyweb/0f575f6c-2d97-4acc-90f9-0ce0544bf745/?source=create).

## Что ещё не проверено

- Работа Preview с реальным U1 и длительная реальная печать.
- Полный сценарий в нативном Mac-приложении и реальная нарезка Snorca с внешним каталогом.
- **Windows GUI и реальная нарезка Snorca на Windows не проверены.**
- Другие версии Spoolman, сервер за авторизацией reverse proxy и самоподписанный HTTPS в Preview не поддержаны.

Реальный принтер, установленный Tracker и пользовательские данные при разработке не изменялись.
Публикация релиза и слияние в main не выполнялись.

Следующий шаг: пользовательская проверка отдельного Preview сначала в режиме чтения,
затем на тестовой катушке с единственным отправителем. Подробности: [руководство](../guides/spoolman-preview-ru.md).
