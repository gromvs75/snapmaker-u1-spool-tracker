Snapmaker U1 Spool Tracker v1.0.1

Snapmaker U1 Spool Tracker keeps a persistent, per-user inventory for four independent U1 toolheads (T0–T3). Its native macOS/Windows desktop dashboard updates live and stays available from the menu bar/system tray. Snapmaker Orca / OrcaSlicer post-processing checks each used toolhead against its assigned spool before export. Missing or invalid filament metadata fails closed; shortage warnings offer Cancel Export or Proceed Anyway. A configurable safety reserve affects only the check, not consumption.

Export and upload never deduct filament. An allowed export records a planned job. The optional local U1/Moonraker monitor matches actual print filename, G-code SHA-256 and byte size, marks an actual start active, and deducts estimates from the spool IDs captured at preflight once after successful completion. Cancelled/error jobs do not consume the full plan. Persistent run identity prevents a duplicate debit after reconnect or restart. Ambiguous/unverifiable jobs remain for review.

Backup & Restore exports a portable JSON file through a native Save dialog and validates/atomically imports it through a native Open dialog, preserving inventory, settings, and accounting history. Before updating on macOS, quit the app, export a backup outside Application Support, then drag the new app into `/Applications` and choose Replace. AppCleaner/CleanMyMac and similar tools may remove the entire app data folder, including internal backups. The product is local-first, with no cloud, account, or telemetry.

Install: on macOS, download `SnapmakerSpoolTracker-macOS.zip`, unpack it, and place `SnapmakerSpoolTracker.app` in `/Applications`. This unsigned app may require **Open** from the context menu. On Windows, download `SnapmakerSpoolTracker-Windows.exe` and keep it in a stable folder. The Windows native dashboard requires Microsoft Edge WebView2 Runtime. Follow README.md and MANUAL_EN.md / MANUAL_RU.md for Orca setup and backup instructions.

Validation to date: extensive automated tests; packaged macOS app and real Snapmaker Orca post-processing manually tested; Fake U1/Moonraker end-to-end simulator tested; Windows artifact built and tested in GitHub Actions. The Windows GUI and physical Snapmaker U1 hardware have not been manually validated in this cycle.
