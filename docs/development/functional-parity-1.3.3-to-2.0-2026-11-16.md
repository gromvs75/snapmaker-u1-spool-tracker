# Полнота переноса 1.3.3 → 2.0

## Основание

2.0 добавляет UID/RFID, многопринтерный учёт и SQLite к работающему продукту.
Изменение архитектуры не является разрешением удалить существующие функции.
Эталон — опубликованный код 1.3.3, commit
`fdeb1aa11c64bd9a06344c9bcc6433c6bcce4bb1`, его руководства и сборка.
Скриншоты дополняют этот контракт, но не заменяют его.

Контрольная точка до исправления функциональных регрессий:
`checkpoint/2.0-user-candidate-before-functional-parity-2026-11-16` → `eafe187`.
Исходные результаты: 819 passed, 3 skipped; packaged macOS 9/9, 8/8,
Spoolman 10/10. Они не проверяли полноту пользовательских сценариев 1.3.3.
Рабочая ветка `integrate/2.0-user-candidate`; ничего не публикуется.

## Что сохраняется из 2.0

Единственный поток SQLite; UID и ручные назначения; очередь сборщиков нескольких
принтеров; журнал замен; идемпотентные дебеты; сохранённый план и ручное решение;
Spoolman uncertain/review/explicit send; резервные копии с карантином операций;
временная разблокировка и подтверждённый перенос. Старый Store и старый pipeline
списания не импортируются в пользовательский процесс.

## Условия приёмки

Сценарии проверяются по функциям, затем по представлению. Наличие кнопки или
прохождение тестов backend не означает готовность сценария приложения.
Для каждого закрытого разрыва ниже нужны тесты и результат проверки сборки.
Текущая сборка 2.0.0rc1 пока не считается полноценной заменой 1.3.3.
