# Ручной режим и RFID в кандидате 2.0

## Ручные назначения без модуля принтера

Для ручного режима модуль `tracker_uid` и изменение конфигурации Klipper не нужны.
Tracker отдельно проверяет связь с Moonraker, состояние печати и доступность RFID.
«RFID / UID · нет модуля» не означает отсутствие связи с принтером.

1. Сохраните адрес в **Настройки → Принтер**, проверьте соединение и явно подключите принтеры.
2. Добавьте катушку в **Катушки → Библиотека** либо выберите уже имеющуюся,
   в том числе связанную со Spoolman. UID для этого не требуется.
3. Когда принтер свободен, в **Головки T0–T3** выберите реальные катушки и нажмите
   **Подтвердить расположение**. Подтверждение назначения ничего не списывает.
4. При непрерывном наблюдении Tracker относит расход к этим катушкам. Замена
   физической катушки должна сопровождаться изменением назначения в Tracker.

Катушку с сохранённым UID также можно назначить вручную, если этот UID сейчас
не подтверждён считывателем в другом месте. Это не превращает ручное назначение
в RFID-подтверждение. Одновременное обнаружение одной катушки на двух местах
блокирует оба назначения до устранения конфликта.

При потере связи ручное подтверждение перестаёт быть доказательством неизменности
катушки. После восстановления связи проверьте расположение снова. Если печать
продолжается, назначение менять нельзя. Прерванное задание сначала разрешите
через историю: сохранённый план можно просмотреть, количество исправить и явно
подтвердить дополнительный расход. Уже учтённая часть повторно не списывается.
Повторное подтверждение расположения не восстанавливает задним числом наблюдение
за прошлым заданием.

**Коррекция остатка**, **подтверждение расположения** и **учёт задания** — разные
операции. Если остаток уже исправлен вручную, не списывайте тот же расход ещё раз
в истории; используйте закрытие без дополнительного списания. Для Spoolman
неопределённая отправка по-прежнему требует отдельной сверки и явного разрешения.

Без связи можно работать с сохранённой библиотекой и историей. Подтвердить текущее
физическое назначение для автоматического учёта можно только при свежем состоянии
свободного принтера. Повреждённый/несовместимый UID-ответ не даёт автоматического
перехода к доверенному ручному назначению.

## Что требуется для RFID

Цепочка чтения: штатный считыватель U1 → совместимый дополнительный модуль
`tracker_uid` в Klipper → объект `tracker_uid` в Moonraker → Tracker → UID катушки
в SQLite. Сам UID не содержит достоверного остатка в граммах: при первой регистрации
вы выбираете существующую катушку либо создаёте новую с материалом и остатком.

Предусмотрена установка отдельного Python extra и отдельного `tracker_uid.cfg`,
подключаемого через `[include tracker_uid.cfg]`. Одна строка конфигурации без модуля
чтение UID не добавит. Подмена всей прошивки не является текущим способом интеграции.
Совместимость должна проверяться по фактической версии/хешу драйвера принтера.

**Установка на реальный U1 ещё не проверена и в этом этапе не выполнялась.**
Имеющийся установщик предназначен только для маркированных файловых симуляторов;
он проверяет совместимость, сохраняет исходные файлы и позволяет откат. Это не
пользовательский установщик для принтера. Не переносите стендовые команды на U1.

[Пакет установки/отката: порядок проверки и ограничения](rfid-module-install-ru.md).

В кнопке **RFID / UID** и панели регистрации теперь различаются:

- канал готов и число новых меток;
- модуль не установлен — доступны ручные назначения;
- модуль найден, считыватель не готов;
- несовместимые/некорректные данные;
- подключения остановлены или связь потеряна.

При готовом канале видны состояния T0–T3: метка читается, отсутствует, не читается,
чтение устарело или возник конфликт. Ноль новых меток сам по себе не подтверждает
работоспособность RFID. Новая метка регистрируется только из наблюдения принтера,
с явным подтверждением привязки; повтор пакета не создаёт вторую катушку.

Для следующего этапа физической проверки нужны отдельное разрешение, свободный
принтер, проверка совместимости его драйвера и подготовленный откат. Только после
этого можно проверять настоящие метки, антенны, снятие/установку и перезапуск U1.
Автодозаправка и сопоставление материалов слайсера головкам до отправки остаются
отдельными исследованиями; этот этап не снимает их ограничения.
