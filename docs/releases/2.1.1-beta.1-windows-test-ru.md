# Сообщение тестировщику Windows

Привет! Подготовил **Tracker 2.1.1 beta**. Предыдущую бету можно пропустить. Здесь есть всё, что я просил проверить в ней, плюс более гибкий прогноз по цвету после нарезки.

Скачай [Snapmaker-Tracker-2.1.1-beta.1-Windows-x64.zip](https://github.com/gromvs75/snapmaker-u1-spool-tracker/releases/download/v2.1.1-beta.1/Snapmaker-Tracker-2.1.1-beta.1-Windows-x64.zip) из [релиза 2.1.1 beta](https://github.com/gromvs75/snapmaker-u1-spool-tracker/releases/tag/v2.1.1-beta.1). Сделай резервную копию в Tracker и закрой старую копию через «Выход». Распакуй ZIP целиком, оставь папку `_internal` рядом с EXE. В заголовке проверь версию `2.1.1-beta.1`. Для окна нужен Microsoft Edge WebView2 Runtime.

1. **Подключи U1 и подтверди катушки.** Пока принтер свободен, в «Обзор → Назначения» сверь реальные катушки на T0–T3 и нажми «Подтвердить расположение». Запиши текущие остатки. Для тестов учёта достаточно заводской прошивки и ручных назначений.
2. **Прогноз после нарезки в Orca.** Нарежь небольшую модель. Проверь в «Обзор → Прогноз нарезки» номер стола и граммы. Если используешь несколько столов, сверь их по отдельности. Строка `; TRACKER_BED_V1 = {plate_number}` должна быть первой в «Г-код начала печати» **выбранного профиля принтера**. Если один цвет однозначно подходит, близкие оттенки одного типа материала должны давать оценку на этой катушке. До запуска печати остатки должны сохраниться.
3. **Смесь и переназначение в Orca.** Если удобно, нарежь небольшой объект смесью №5 из двух совместимых материалов. Проверь, что расход показан для обоих исходных материалов. В **Print Preprocessing** назначь один из них на другую подходящую головку. После запуска на Windows сверь подписи «По G-code» и «После ≈» с фактически выбранной головкой. После завершения проверь, что расход этого компонента учтён с её катушки. Автоматическое всплытие при смене головки до старта в этой бете проверено на Mac. Windows здесь проверяем по текущей печати и истории.
4. **Печать из Snapmaker Space с телефона.** Закрой Orca и запусти с телефона короткую печать на этом же U1, по возможности на нескольких головках. **До конца печати оставь Tracker запущенным и подключённым, а компьютер включённым и без перехода в сон.** После чтения файла на используемых карточках должны появиться «По G-code» и «После ≈». После завершения сверь остатки и «Историю». Расход должен учесться один раз, в том числе если принтер быстро вернулся в ожидание. Можно перезапустить Tracker и проверить, что повторного списания нет.
5. **Если пользуешься Spoolman**, после печати обнови каталог и сверь остатки с «Обзором». При нехватке данных Tracker может запросить проверку задания. В этом случае пришли детали задания из «Истории».

Будет достаточно версии Windows, Orca и прошивки U1, скрина «Головки и катушки» во время печати и снимка записи в «Истории» после завершения. Если прогноз пропадёт, раскрой «Обзор → Детали» и укажи, как запустил печать и какую головку выбрал.
