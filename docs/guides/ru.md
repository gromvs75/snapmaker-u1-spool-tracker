# Tracker 1.2.1 — инструкция к готовящемуся выпуску

**1.2.1 пока не опубликована. Windows GUI и настоящая нарезка Snorca на Windows остаются непроверенными.** См. [заметки к выпуску](../releases/1.2.1.md).

## Как работает прогноз

1. Оставьте Tracker работающим в строке меню/трее.
2. Проверьте назначения катушек T0–T3 и их остатки.
3. Выполните Slice в Snorca. Для нового прогноза не нужны ручной экспорт G-code, выбор файла, изменение скриптов постобработки или сборка своего слайсера.
4. Завершённая нарезка обновляет значок и меню. На macOS меню раскрывается автоматически, основное окно остаётся скрытым, значка Dock нет. На Windows меню открывается вручную. Изменение остатка обновляет результат, но не раскрывает меню.
5. Нажатие на прогноз в меню открывает «Обзор» для последней завершённой пластины. Другую пластину можно выбрать внутри окна; это не меняет статус последней нарезки в меню. Закрытие окна оставляет Tracker работать; «Выход» завершает приложение.

Меню показывает пластину и время: ✓ — хватает с резервом, ✕ — дефицит, нейтральный статус — нет прогноза или не назначена используемая катушка. Строки меню переведены на EN/RU/DE/UK/ES.

Возле используемых головок: зелёное ✓ — материала хватает с резервом, красное ✕ — не хватает. Отображаются расход, текущий остаток и прогноз после печати либо дефицит с резервом. Неиспользуемые головки имеют нейтральный статус. Резерв учитывается один раз на используемую катушку; расход нескольких головок с одной катушкой суммируется.

**Нарезка ничего не списывает и не резервирует.** Повторная нарезка обновляет прогноз. Этот механизм не отправляет G-code и не запускает, не останавливает и не блокирует печать. Учёт фактически наблюдаемой печати — отдельная функция. Во время печати, в том числе на паузе, головки сохраняют её данные; сводка новой нарезки показана отдельно.

## База и резервные копии

1.2.1 сохраняет каталог базы и порт версии 1.2 beta. Если этой базы нет, создаётся пустая. Данные старых стабильных версий и Menu Test 1/2 автоматически не импортируются:

- macOS: `~/Library/Application Support/SnapmakerSpoolTracker-Beta12/`.
- Windows: `%LOCALAPPDATA%\SnapmakerSpoolTracker-Beta12\`.
- Локальная панель: `http://127.0.0.1:8766`. Для резервных копий используйте нативное окно, не обычный браузер.

Для намеренного переноса экспортируйте JSON из старой версии в папку вне базы. Импортируйте его через «Настройки» новой версии. Импорт заменяет сохранённые данные и создаёт страховочную копию прежнего состояния. Затем проверьте катушки, назначения, остатки и резерв. Синхронизации со старыми стабильными версиями и Menu Test 1/2 нет.

**Обычная резервная копия может содержать включённый монитор принтера.** В офлайн-стенде используйте только изолированный режим: он отключает настройки принтера при импорте, не запускает монитор и блокирует команды принтера, отправки и списания. Личная база для теста не нужна.

## Ограничения

- Соответствие **1→T0 … 4→T3 предполагается**, а не подтверждается принтером. Пометка остаётся в «Обзоре».
- Расход — оценка слайсера, остатки — данные учёта. Зелёная отметка не гарантирует успешную печать.
- Прогноз относится к проекту последней завершённой нарезки. Открытие или изменение другого проекта само по себе его не переключает.
- Недописанный файл не создаёт нового прогноза; остаётся предыдущий завершённый результат с его временем.
- Наблюдатель рассчитан на временные результаты Snorca 2.4.1 non-BBL: `<временная папка ОС>/snapmaker_orca_model`. Произвольные версии/другие слайсеры не проверены. Для нестандартной папки доступен `--slice-root PATH`, без изменения настроек Snorca.
- После очистки временных файлов может потребоваться новая нарезка. Постоянная база катушек хранится отдельно.
- Прогноз переведён на RU/DE/EN; для других языков используется EN. Это не обещание полной локализации остальных экранов.

## Windows-тестирование

У владельца проекта нет Windows. От него не требуется установка Windows или выполнение Windows-инструкций на Mac. Для отдельного тестировщика подготовлен [комплект Windows Sandbox](../../dev/windows_slice_check/README_RU.md): сеть выключена, папка хоста доступна только для чтения, база искусственная. Snorca и офлайн-зависимости добавляются отдельно. Сам комплект здесь не запускался.

Короткая проверка Windows: Slice → обновление значка и меню; повторный Slice → новый прогноз; две пластины → отдельные прогнозы; нехватка → красный ✕; после перезапуска данные сохраняются. Нарезка не должна менять остатки. Меню и открытие окна по нажатию проверяются визуально. Автораскрытие меню реализовано только на Mac.

Подробности запуска `--isolated-root` и диагностики: [English guide](en.md). Перед отправкой журналов удалите личные пути, имена файлов, адрес принтера и содержимое резервных копий.
