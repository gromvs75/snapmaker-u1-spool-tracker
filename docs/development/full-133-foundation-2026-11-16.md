# Полная 1.3.3 как пользовательская основа 2.0

Поручение пользователя от 16 ноября: сохранить полноценную 1.3.3, её функции и
пять языков; подключить существующее ядро UID/SQLite, несколько принтеров и
пожелания тестировщика. Не продолжать сокращённую оболочку как основное приложение.

## Последовательность

Предложения тестировщика включаются **в интеграцию 2.0**, а не в отдельную новую
ветку исправлений стабильной 1.3.3. Сначала переносится полный слой представления
1.3.3 без её глобального Store, затем его действия подключаются к командам
единственного SQLite-владельца. Изменять старые данные или запускать установленную
1.3.3 для этого не требуется. Новый renderer не становится пользовательским
entrypoint до проверки его действий: одинаковый экран не доказывает интеграцию.

Источник интерфейса: опубликованный commit
`fdeb1aa11c64bd9a06344c9bcc6433c6bcce4bb1` из отдельного локального checkout.
Из него переносится исходный HTML и шесть модулей представления: sender, forecast,
Spoolman, сравнение имён, settings, inventory. Функции старого учёта и глобальный
Store не импортируются и не запускаются. Windows и macOS проверяются отдельно;
новый Windows Actions без разрешения не запускается.

## Сценарии тестировщика — критерии приёмки

| Сценарий | Требуемое поведение | Состояние ядра / необходимая работа |
|---|---|---|
| Раскрыть задание без принтера и слайсера | Исходный план, исходные катушки/головки, уже учтённое, причина пропуска | HistoryReview уже есть; подключить к строке истории 1.3.3 |
| Tracker видел старт, затем был выключен | После перезапуска предложение «Печать завершилась успешно?»; списать / отложить / закрыть без списания | Решения сохраняются; добавить предложение в полную оболочку |
| Подтвердить расход | Показать план и **дополнительный** расход, дать исправить, записать решение | Частичный учёт, смена катушки, stale revision, повтор запроса и uncertain Spoolman уже защищены; проверить через новую оболочку |
| Spoolman | Локальный дебет и очередь; неизвестный результат не повторять автоматически | Сохранить Delivery и явную отправку, не возвращать старый pipeline |
| Прогноз до отправки | Обновление после завершённой нарезки, до загрузки на принтер; источник, пластина и время | Есть SliceObserver и новые проверки; реальные задержки не объявлять объяснёнными |
| Пластины 1/2/3 на скриншоте | Это обнаруженные результаты нарезки, а не доказательство выбранной пластины в слайсере; просмотр не меняет текущую печать | Уточнить подписи без удаления выбора пластин; проверить разные проекты и повторную нарезку |
| Остаток 125.259999… и обрезанный расход | Отображение до 0,1 г в обзоре, истории, меню, списках; сумма помещается в головке | Форматирование отдельно от хранения мг и расчёта; не округлять редактируемые исходные значения |
| Пропуски при работающем компьютере | Отдельное расследование по журналам, проверка связи/наблюдения/идентичности задания | Включённый компьютер не доказывает непрерывность; ручное подтверждение не закрывает причину |

Старые задания без сохранённого плана нельзя достоверно восстановить из текущих
катушек. При замене катушки нельзя предлагать весь первоначальный план старой
катушке. Неопределённая внешняя отправка уже входит в локальный дебет.

### Что ещё не подключено к полной оболочке

Нельзя переключать launcher, пока не проверены все следующие группы:

- Все действия библиотеки: создание/назначения/цвет/взвешенный остаток/удаление/
  параметры; безопасная адаптация UID вместо произвольного редактирования метки.
- Выбор и подключение нескольких принтеров, проверка адреса, чтение счётчиков;
  сообщения о совместимости модуля RFID и состояния регистрации меток.
- Каталог, поиск, сравнение имён и очередь Spoolman; новая сверка uncertain вместо
  старой команды отправки. Неподключённые маршруты возвращают явную ошибку,
  а не вымышленное состояние сервера.
- Резервные копии/миграция и нативные диалоги, состояние подключения, исходные
  статистические сводки, трей и проверка выдаваемых пакетов.

Неподключённые старые HTTP-команды возвращают явную ошибку **без изменения данных**.
Они не направляются в старый Store. Само наличие соответствующей кнопки не считается
выполненным переносом. Стабильная 1.3.3 и рабочие пользовательские данные не менялись.
