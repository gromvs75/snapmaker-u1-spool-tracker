# Запуск Tracker 2.1.0rc2

Распакуйте весь архив. Windows: запускайте Snapmaker-Tracker-2.1-Candidate.exe
вместе с папкой _internal. Mac Apple Silicon: запускайте одноимённое .app.
Не запускайте старый и новый кандидат одновременно. Сохраните резервную копию
старого приложения перед переходом.

Данные кандидата 2.1 сохраняются в том же профиле, что у rc1:

- Mac: ~/Library/Application Support/Snapmaker Tracker 2.1
- Windows: %LOCALAPPDATA%\Snapmaker Tracker 2.1

Профиль установленного Tracker 1.x отдельный. Переход из 2.0/1.x выполняйте через
экспорт и импорт резервной копии, а не копированием SQLite вручную. После импорта
проверьте остатки и назначения; подключения и отправка запускаются явно.

Закрытие окна прячет приложение в строку меню/трей. Для полного завершения используйте
«Выход» в меню значка. После запуска приложения сначала дождитесь загрузки экрана,
затем открывайте импорт или настройку подключения. Если действие зависло, сохраните
время и журнал; повторно не подтверждайте финансовый учёт вслепую.

Mac-приложение подписано локальной ad-hoc подписью, без Apple notarization.
Windows EXE без сертификата издателя. Архивы предназначены для согласованного тестирования.

В комплекте: инструкция по меткам, изменения, ответ тестировщику, commit сборки и
результаты выполненных проверок. Нативный Windows GUI считается проверенным только
при наличии успешного отчёта WINDOWS-GUI-VERIFIED для этого же commit.
Установку RFID-модуля на реальный принтер сейчас не выполняйте.
