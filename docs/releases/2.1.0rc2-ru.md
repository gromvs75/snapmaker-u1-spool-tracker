# Tracker 2.1.0rc2 — кандидат для Mac и Windows

Обе платформы собираются из одного коммита. Точный commit и результаты проверки
лежат рядом с приложением в BUILD-INFO и файлах проверки. Это кандидат для испытаний,
не опубликованный стабильный релиз. Реальный принтер при подготовке не использовался.

Из rc1 сохранены исправление одиночного HTTP-тайм-аута при доверенном наблюдении,
сохранённый план с подстановкой дополнительного расхода, необязательный комментарий,
последовательный учёт Tracker → Spoolman в одном окне и защита от повторного списания.
Восстановление резервных копий 1.x и 2.x поддерживается с проверкой структуры.

Добавлено в rc2:

- Mac: обычное Cocoa-окно вместо неактивирующейся панели устраняет воспроизведённое
  пустое окно WebKit. Сохранён режим без значка Dock; меню активного приложения
  теперь переключается на Tracker. Проверены нативный импорт, отмена и Cmd+Q.

- Локальный снимок SpoolmanDB: 10 058 изделий. Предлагает параметры при однозначном
  совпадении свойств; не ищет катушки по UID, не определяет фактический остаток.
- Автоматическая связь разных UID OpenPrintTag по явному instance_uuid. Для Bambu
  сохраняется связь по общему ID блока 9. Общий ID переживает restart и backup;
  потерянный ответ Spoolman не вызывает создание второй записи с другой стороны.
- Проверки конфликтов ID, материала, занятого UID и одновременного размещения.
  Другие одинаковые по материалу/цвету катушки не объединяются.
- Неоднозначная подпись «Разрешить прерванное задание» заменена на «Закрыть без
  списания». Пояснение направляет к «Проверить» для учёта расхода и явно сообщает,
  что действие завершает наблюдение Tracker и не управляет принтером.
- Подготовлены отдельные инструменты установки/OFF/отката RFID на офлайн-копии U1.
  Модуль 0.8.0 входит в исходники; приложение само ничего не устанавливает на принтер.

Новые функции требуют нового приложения; для получения instance_uuid нужен также
новый модуль чтения. Его установка на настоящий U1 пока не выполнялась и не разрешена
этим комплектом. Без модуля доступен ручной учёт. Подробности — в инструкции по меткам.

Ограничения: все варианты ключей и физических меток не проверены на железе;
ISO15693 заводских меток Prusa не поддерживается reader U1. TigerTag timestamp и
OpenTag3D batch ID не считаются гарантированно уникальными ID катушек.
Каталоги и карты кодов неполны. Нужен явный фактический начальный остаток.

По новому снимку тестировщика из версии 2.0 виден прерванный учёт, но причина
конкретного пропуска неизвестна без диагностической записи. Этот случай не объявлен
исправленным только по скриншоту. Сообщение о зависании Mac после импорта/соединения
также не позволяет утверждать устранение всех причин: результаты конкретных проверок
нового пакета приложены отдельно.

До появления успешного отчёта проверки именно rc2 Windows GUI считается непроверенным.
Отчёты предыдущего rc1 не заменяют проверку этой сборки.
