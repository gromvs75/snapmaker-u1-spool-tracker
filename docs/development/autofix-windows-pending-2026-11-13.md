## Существенный конфликт, вопрос пользователю ожидает ответа

В изображении написано «Все авто-действия можно откатить в течение 10 минут»;
предлагаются повтор после проверки остатка и отправка без manual approve,
показаны 78/63/71% уверенности. Backend не поддерживает отмену уже применённого
Spoolman PUT, баланс не доказывает применение конкретного списания, оснований
для этих процентов нет. Прежние явные требования запрещают автоматический
повтор неопределённой отправки.

Предложены варианты:
1. Рекомендуемый: сохранить вёрстку, заменить неподдерживаемые подписи на
   безопасные предложения; сохранить ручную сверку и явную отправку.
2. Сохранить подписи макета, но заблокировать неподдерживаемые действия и
   явно объяснить ограничения (не выдавать проценты за реальные оценки).

Функциональное поведение предложений пока не реализовано, push/Actions не
выполнялись. В src/tracker_uid_gui.html есть незакоммиченная подготовка CSS
геометрии и сворачивания сырого журнала — это НЕ готовый Auto-Fix Queue.
Разрешение на push/Actions сохраняется, повторно его спрашивать не нужно.

## Подготовленные независимые проверки

- `native_windows.py`: обычный текущий EXE, реальное окно, WM_CLOSE→hide,
  поиск значка на панели задач через UI Automation, фактическое меню
  «Открыть Tracker» / «Выход», проверка завершения процесса и освобождения базы.
  На Windows ещё НЕ исполнялось.
- `live_exe.py`: внешний клиент обычного packaged launcher без прежнего
  лабораторного --ci-live. Два настоящих Klipper/Moonraker, verified G-code,
  расход, потеря связи, восстановление копии, restart/replay.
- Supervisor дополнен G-code/metadata и опцией локального source;
  исправлены длинный Unix socket path, маскировка исходной ошибки cleanup,
  ложный конфликт порта TIME_WAIT в probe (SO_REUSEADDR, не SO_REUSEPORT).
- Новый workflow дополнен native UI, WSL и внешним клиентом текущего EXE.
  Добавлен push trigger только этой интеграционной ветки, поскольку новый
  workflow_dispatch может отсутствовать в default branch. Никаких изменений
  default branch для запуска не требуется.

Локально клиент проверен с предыдущей собранной macOS 2.0: **7/7**, 3 списания,
после restore/restart без дублирования. Это не Windows-проверка. Изолированные
процессные стенды остановлены через собственный authenticated supervisor.
Артефакты: `output/current-live-local/unified-live-result.json`, `processes.json`.
Выборочные UID/Spoolman/settings/shell/collector регрессии: **86 passed**, 17.46 с;
