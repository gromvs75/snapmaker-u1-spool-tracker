# Tracker 1.3.3

Stable release based on the user-tested 1.3.3rc5 interface and fixes. Windows x64
and macOS Apple Silicon packages use the same application source.

## Changes

- Fixes Windows startup lock error handling, unresponsive tray/window behavior,
  and exposing native window objects through the JavaScript API.
- Unified left navigation in Settings and Spools, colored spool icons, Library
  and Toolheads T0–T3 views, and Add and assign for local spools.
- Spoolman labels include the manufacturer. Live search supports name,
  manufacturer, material and ID. Linked names can be compared and updated without
  changing stock, history or assignments. Separately created spools are not merged.
- Retains the 1.3.1 completed-print forecast and 1.3.2 cancellation-accounting fixes.

## Upgrade

Export a JSON backup, quit the old Tracker (including its tray/menu-bar process),
then replace the application. Do not run two accounting instances for one printer.
The data folder remains `SnapmakerSpoolTracker-Beta12`; the old folder name does
not indicate the application version. Do not delete the database or lock file.
If your Snorca post-processing command contains a versioned application path,
update it to 1.3.3. See the [English guide](../guides/en.md).

## Validation and limitations

A Windows user confirmed rc5 startup/exit, spool search, Spoolman attachment and
detachment, local/remote assignment replacement and settings persistence.
Ordinary completed-print accounting and delivery to Spoolman were also confirmed
in the release-candidate series. This does not establish every Windows or printer scenario.

Automatic replenishment and manual spool replacement during printing remain
**experimental**. A print can finish successfully while usage remains unaccounted
if observation is interrupted or counters disagree. Such a job does not send
consumption to Spoolman. Keep the computer awake and Tracker running for observation.
Usage is an estimate, not a scale measurement. Name synchronization is unrelated
to physical spool identification or automatic replacement.

macOS: Apple Silicon (arm64), ad-hoc signed, not notarized. Windows: x64,
Microsoft Edge WebView2 required for the native window.
Spoolman is optional, separately installed; tested integration target: 0.27.1.

## Русский

Стабильная 1.3.3 основана на проверенной пользователем rc5. Исправлены запуск,
трей и окно Windows. Настройки и катушки получили единое меню слева, цветные
значки, разделы «Библиотека» и «Головки T0–T3», действие «Добавить и назначить».
В названиях Spoolman показывается производитель; добавлены поиск и обновление
названий связанных записей без изменения остатка, истории и назначения.
Локальные катушки с записями Spoolman автоматически не объединяются.
Исправления 1.3.1 и 1.3.2 сохранены.

Перед обновлением экспортируйте резервную копию и полностью завершите старый
Tracker. Каталог данных `SnapmakerSpoolTracker-Beta12` сохранён. Если путь в
постобработке Snorca содержит номер версии, обновите его на 1.3.3.
[Инструкция](../guides/ru.md) · [Spoolman](../guides/spoolman-ru.md).

Пользователь подтвердил на Windows запуск, выход, поиск, привязку и отвязку,
замену назначений и сохранение настроек в rc5. В серии кандидатов также проверено
списание обычной завершённой печати с передачей в Spoolman.
**Автодозаправка и ручная замена во время печати остаются экспериментальными:**
при неполных данных, прерывании наблюдения или расхождении счётчиков расход может
не списаться. Успешная печать и зелёный прогноз не гарантируют учёт.
Неучтённый расход в Spoolman не отправляется. Для наблюдения компьютер должен
оставаться включённым и не уходить в сон.

macOS — Apple Silicon, без нотарификации; Windows — x64, для окна нужен WebView2.
