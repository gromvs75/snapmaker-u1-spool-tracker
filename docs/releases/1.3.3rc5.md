## Updated rc5 UI candidate (Windows and macOS)

Both packages are built from the same commit. Settings and Spools use consistent left navigation. Spools has Library and Toolheads T0–T3; Add and assign creates a local spool and assigns it in one atomic operation with replacement confirmation. Parameters open for the selected spool. Catalogs show colored front-view spool icons. Spoolman-owned balances are read-only in Tracker.

This replaces the earlier rc5 interface candidate; use BUILD-INFO and SHA256 to distinguish archives with the same version. Test startup/exit, navigation, search, local creation, assignment and Spoolman label display. Native GUI behavior on the tester's machine and actual printing still require user testing. macOS archive targets Apple Silicon and is ad-hoc signed, not notarized. No 2.0.0 changes are merged.

# 1.3.3rc5 — проверка интерфейса Spoolman

Включает исправления rc2–rc4: запуск и трей Windows, производитель в названиях
Spoolman и безопасное обновление имени уже связанной катушки.

## Что изменилось

- Вместо отдельного светлого рабочего пространства — компактное окно в тёмном
  стиле Tracker. Нет повторяющихся слотов, библиотеки и бокового меню.
- Кнопка «Проверить названия» в катушках и настройках Spoolman. Выбор катушки,
  два названия и одно действие «Обновить название в Tracker».
- Если имена совпадают, явно показано, что обновление не требуется.
- Поиск по мере ввода в настройках назначения Spoolman: название, производитель,
  материал или ID (например, `ELEGOO green`, `PETG` или `#2`). Есть поиск в окне названий.
- Поиск не назначает катушку автоматически. Сначала выберите запись из результатов,
  затем головку T0–T3 и нажмите «Назначить». Пустая выдача отключает назначение.
- Добавлено пояснение: обновление имени не объединяет локальную катушку и отдельно
  созданную запись Spoolman. Одинаковые имена могут принадлежать разным катушкам.

## Проверка

1. Сделайте резервную копию и полностью завершите прежний Tracker.
   rc5 при обычном запуске использует прежний каталог данных, а не отдельную базу.
2. Проверьте запуск, меню трея, скрытие и повторное открытие окна, выход.
3. Откройте «Катушки» → «Проверить названия». Проверьте поиск, выбор, фильтры,
   закрытие кнопкой и Escape. При совпадении имён ничего менять не нужно.
4. Если имя различается, обновите его и проверьте сохранность остатка и назначения.
5. В настройках Spoolman введите часть названия или производителя. Проверьте
   поиск по материалу и ID, пустой результат и очистку запроса. Назначайте только
   катушку, действительно установленную на выбранной головке, перед новой печатью.
6. При ошибке пришлите tracker.log, снимок и последовательность действий.

Печать для проверки интерфейса не требуется. Не запускайте два Tracker для учёта
одного принтера. Учёт ручной замены во время печати, автодозаправка и чтение сторонних
меток в эту сборку не добавлены. Локальные дубли автоматически не удаляются и не сливаются.

Windows GUI на машине тестера для rc5 пока **НЕ ПРОВЕРЕН**. Проверки CI используют
изолированную базу и фиктивный Spoolman. Mac и 2.0.0 пока не объединяем: ждём отзыва.

## English

rc5 retains rc2–rc4 fixes and replaces the large comparison workspace with a compact
Tracker-themed dialog. Live search in Spoolman assignment supports name, manufacturer,
material and ID. Explicit selection is required; search does not assign a spool.
Name updates preserve balances, history and identity; they do not merge local and
Spoolman records. Back up your inventory and quit the previous Tracker before running.
This build uses your existing data directory. User-machine Windows GUI verification
is pending. No manual replacement accounting or RFID features are added.
