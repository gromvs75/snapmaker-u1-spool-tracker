Нулевой код возврата команды stop и удалённый PID-файл недостаточны как допуск
к записи. Даже пауза наблюдения без процесса не заменяет исключительный контроль
над тем, кто может его запустить. Поэтому на данном этапе **не добавлен реальный
stop/restart, не выбран обход штатных проверок MCU и не включён установщик U1**.

## Что подготовлено

`scripts/rfid_readonly_audit.py` — самостоятельный stdlib-скрипт без subprocess,
сетевых вызовов, записи файлов, kill, команд принтеру или импорта vendor-кода.
Режимы запуска только явные: `--fixture-root` либо `--read-only-u1`.
Выход — JSON в stdout, редирект выполняется локально на Mac.

Обход upper идёт через дескрипторы каталогов с O_NOFOLLOW, без обхода ссылок
и чтения спецфайлов. Записываются типы (включая возможный char-device whiteout),
права/UID/GID, хеши обычных файлов и видимых xattrs, предупреждения о лимитах,
нечитаемых атрибутах, hardlink и изменениях во время обхода.
Неатомарность и неполнота привилегированных xattrs явно сохранены в результате.
Это диагностика, а не полный backup/recovery фактического OverlayFS.

Сравниваются два наблюдения PID/start ticks. Отдельно отмечаются старый PID-файл,
повторное использование PID, другой процесс после перезапуска, несколько
кандидатов Klipper и недоступные сведения. Совпадение наблюдений не разрешает запись.

На macOS используемый Python не предоставляет os.listxattr: тестовый CLI честно
показывает неполную инвентаризацию. Не подменяем её «успехом». Проверка Linux/U1
по-прежнему нужна; для неё подготовлен один вызов SSH с вводом пароля в Terminal.

## Попытка чтения с U1

В рамках ранее разрешённой read-only диагностики сделана одна попытка SSH:
BatchMode=yes, StrictHostKeyChecking=yes, pinned host-key algorithm ed25519,
без перебора паролей и изменения known_hosts.
Результат: **Permission denied (publickey,password)**, код 255.
Удалённый Python не запущен; новый снимок overlay/процессов не получен.
Журнал: `output/u1-rfid-readonly/overlay-service-audit-ssh.log`.
Пустой `overlay-service-audit.json` не является диагностическим результатом.

Дальнейшее чтение требует ввода пользователем пароля в его Terminal:
[одна команда и описание собираемых данных](../guides/u1-rfid-overlay-audit-ru.md).
Пароль в чат не запрашивается. Принтер, установленные приложения и базы не менялись.
