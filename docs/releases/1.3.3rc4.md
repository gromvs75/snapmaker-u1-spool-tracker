# 1.3.3rc4 — Spoolman name comparison (Windows test build)

Based on rc3; preserves the Windows startup/tray fixes and manufacturer labels.

Open **Compare names / Сравнить названия** in the spool inventory or Spoolman settings. The new light workspace compares the current Tracker name with the composed Spoolman name. Sync changes only the local name. Spool identity, slots, balances and consumption history are unchanged; nothing is written to Spoolman by this action.

Already matching names need no action. Existing automatic catalog refresh may already have corrected the name. Outdated comparison data requires Refresh; stale names cannot overwrite a newer edit.

## Проверка пользователем

1. Сохраните резервную копию и завершите предыдущий Tracker. При обычном запуске rc4 использует существующий каталог данных — архив не создаёт отдельную пользовательскую базу автоматически.
2. Откройте «Катушки» → «Сравнить названия» (также доступно в настройках Spoolman).
3. Проверьте выбор катушек, обе колонки, фильтры и закрытие через «Назад» или Escape.
4. Если есть различающееся название, нажмите «Синхронизировать название». Проверьте производителя в библиотеке и обзоре. Остаток и привязка должны сохраниться. Если название уже совпадает, не нужно специально портить его для проверки.
5. Проверьте меню трея, повторное открытие окна, выход и повторный запуск. Если возникнет проблема, пришлите tracker.log, снимок экрана и описание действий.

Initial screen checking does not require a print. Do not run two Tracker versions accounting for the same printer. This build does not add manual spool-replacement accounting or third-party RFID reading; those are separate research / 2.0.0 work.

Native CI checks the tray and comparison window on synthetic data, then runs the packaged self-test. **GUI verification on the affected user's Windows machine and real Snorca workflow remain UNVERIFIED for rc4.** macOS packaging is version-aligned in source but is not being released in this round.
