# Пакет документов к 1.2 beta — тексты для проверки в PR

Документация включена в ветку PR вместе с кодом 1.2 beta. Тексты GitHub Release, Reddit и Snapmaker Forum остаются заготовками: релиз, тег и сообщения не публикуются этим PR. Успешные пакеты `83be812` предшествуют добавлению документации; результаты проверок новой вершины ветки отображаются в PR.

## Что подготовлено

- [README проекта](../../README.md): заметный блок кандидата 1.2, ссылки на новые инструкции; прежние инструкции 1.0.1 сохранены и явно обозначены.
- [English guide](../guides/en.md) и [русская инструкция](../guides/ru.md): прогноз, резерв, пластины, отдельная база, резервные копии, изоляция и ограничения.
- [Release notes](../releases/1.2-beta.md): точная матрица проверок.
- [GitHub Release](GITHUB_RELEASE_EN.md): заголовок, предполагаемый тег и тело будущего pre-release.
- В старых MANUAL_EN.md, MANUAL_RU.md и сводной документации добавлены указатели на версию 1.2; исторические инструкции не переписаны как будто они относятся к новой сборке.

## Формулировки, которые сохраняем во всех публикациях

1. Windows GUI и настоящая нарезка Snorca на Windows ещё не проверены. Успешная сборка/self-test EXE этого не подтверждает.
2. Реальный Slice проверялся на Mac в Lab; основная интегрированная программа — в Mac-окне на изолированных файлах. Эти проверки не смешиваются.
3. Нарезка ничего не списывает, резерв не расходуется; прогноз не запускает печать и не является строгой блокировкой Send/Print.
4. Карта материалов 1→T0 … 4→T3 пока предполагается.
5. Beta использует отдельную пустую базу; обычный импорт может включить сохранённый монитор. Изолированный режим принудительно блокирует доступ к принтеру.
6. Владелец проекта не имеет Windows: проверка адресована отдельному тестировщику, а не требует установки Windows на его Mac.

## Перед будущей публикацией

- Согласовать тексты и канал публикации. Пока не публиковать.
- Повторно проверить актуальные артефакты/контрольные суммы и статус Windows GUI. Если GUI так и не проверен, заметная оговорка остаётся.
- CI-артефакты имеют срок хранения. Только после создания релиза добавить реальные постоянные ссылки на его вложения; сейчас выдуманных release URL нет.
- Заголовки «draft — not posted/published» и этот файл — редакторские пометки, их не переносить в сообщение.
- Не утверждать, что файл настройки Sandbox равнозначен выполненному Windows-тесту, что поддержан Intel Mac, или что все языки интерфейса полностью переведены.
- Не отправлять личные резервные копии, адрес U1 или пользовательские профили вместе с публичными материалами.

Источник фактов: текущий код, BUILD-INFO.json кандидата, [проверка итоговых сборок](../../dev/BETA12_RENAME_AND_CI_RU.md) и [предыдущая интеграционная проверка](../../dev/BETA12_INTEGRATION_VALIDATION_RU.md). Итоговые пакеты повторно проверены через `--self-test`; прежние проверки окна описаны отдельно. При вычитке приложения не запускались, установленный Tracker, реальный U1 и пользовательские настройки не затрагивались.
