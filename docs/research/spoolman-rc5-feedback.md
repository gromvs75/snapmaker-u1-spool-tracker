# rc5: замечания тестера rc4

2026-11-11. Ветка `ui/spoolman-rc5`, основана на rc4 `b123d00`.
Тестер подтвердил открытие/закрытие rc4 и совпадающие названия, но отметил
перегруженное светлое окно и отсутствие поиска при назначении Spoolman.

Решение: компактный диалог в существующих цветах Tracker, один список и две
карточки названий. Поиск по мере ввода в диалоге и настройках; состояние совпадения
объясняет отсутствие действия. Явное пояснение про независимые записи, без
автоматического слияния по имени. Функции списания/назначения не перерабатывались.

Lazyweb: https://www.lazyweb.com/report/lazyweb/8cbd21f3-5fee-4ba9-b14e-d3b75143633a/?source=create
Отчёт подготовлен по снимку прежнего стенда и конкретным замечаниям пользователя.

Проверки: сохранены backend-тесты защиты имени; расширен native Windows probe
до 12 сценариев, включая поиск и отсутствие записи при поиске/выборе, пустую выдачу,
сохранение выбора при обновлении каталога. На браузерном стенде эти сценарии прошли;
проверены 1400px и 390px без горизонтального переполнения.

Перенос в 2.0.0 пока запрещён: ожидаем ответ на rc5. Для будущего переноса брать
rc5-версию UI вместо прежнего светлого rc4, сохранив проверки имени/остатка/ID.
Ручная замена и автодозаправка остаются самостоятельными исследованиями.
