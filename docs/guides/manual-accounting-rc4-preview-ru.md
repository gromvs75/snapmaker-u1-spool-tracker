# Tracker 2.1.0rc4-manual-preview для Windows

Тестовая сборка на основе rc4. Исправлено ручное списание для задания из истории без сохранённого плана. После выбора использованной катушки поле «Расход, г» доступно сразу. Кнопка «Добавить ещё катушку» нужна, если в задании было несколько катушек.

1. Между печатями экспортируйте резервную копию. Завершите старый Tracker через «Выход» в трее.
2. Распакуйте архив в отдельную папку. Запустите `Snapmaker-Tracker-2.1-Candidate.exe`. Папка `_internal` должна остаться рядом. В «О приложении» проверьте версию `2.1.0rc4-manual-preview`. Сборка использует существующий профиль Tracker 2.1.
3. Откройте в истории завершённое задание с ещё не учтённым расходом. Нажмите «Указать катушки и расход».
4. Выберите катушку, с которой действительно печатали, и введите расход, который ещё не списан. Подтвердите завершение печати и нажмите «Учесть в Tracker».
5. Для катушки, связанной со Spoolman, в этом же окне можно отдельно подтвердить отправку. Проверьте запись в истории и изменение остатка. Если списание уже выполнено, повторно его не вводите.

Сборка для Windows x64. Используется установленный Microsoft Edge WebView2 Runtime. На принтер ничего устанавливать не требуется.
