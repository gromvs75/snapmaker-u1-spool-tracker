# 1.3.3rc3 — Spoolman manufacturer labels (test build)

Based on 1.3.3rc2. Imported filament names now include `filament.vendor.name`, for example `[Spoolman #2] ELEGOO RAPID PETG Green`. Names without a manufacturer still work; an existing manufacturer prefix is not repeated. Existing attached spools receive the corrected name on the next successful catalog refresh; no detach or reimport is needed.

Spool identities, assignments and consumption logic are unchanged. No database migration or manufacturer write to Spoolman is performed. This does not add automatic accounting for manual spool replacement during a print or change auto-refill support.

The affected Windows user confirmed rc2 tray interaction and normal exit. The rc3 artifact still needs user verification; full real Snorca slicing on Windows remains UNVERIFIED for this build.

## Проверка

После запуска rc3 и успешного обновления каталога Spoolman проверьте производителя в списке выбора, библиотеке катушек и обзоре. Например: `[Spoolman #2] ELEGOO RAPID PETG Green`. Повторно привязывать катушки не нужно.

Это отдельная тестовая сборка, а не изолированная база: при обычном запуске она использует существующий каталог данных Tracker. Перед пользовательской проверкой сохраните резервную копию и завершите предыдущий Tracker. Не запускайте два экземпляра для одного принтера. При разработке установленный Tracker, пользовательская база и реальный принтер не использовались.
