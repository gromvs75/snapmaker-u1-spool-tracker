# Tracker 2.1.0rc4-visual-color-preview

Подготовьте резервную копию из Tracker и завершите его через «Выход» в меню. Распакуйте ZIP в отдельную папку и запустите новую сборку. На Windows оставьте папку `_internal` рядом с EXE. На macOS открывайте приложение из папки, в которой его хотите использовать. Если в Orca настроен скрипт постобработки, проверьте, что он указывает на эту копию. В заголовке Tracker должна быть версия `2.1.0rc4-visual-color-preview`.

Если после отключения модуля UID ручные назначения требуют проверки, подключите свободный принтер в Tracker. Откройте «Обзор → Назначения», сверьте физическое расположение катушек без меток и нажмите «Подтвердить расположение». Сохранённый прогноз обновится автоматически.

Во время печати карточки «Головки и катушки» показывают плановый расход «По G-code» и прогноз остатка после текущего задания. Для печати со Space достаточно подключения Tracker к U1 и доступности файла задания на принтере. Если одновременно нарезать следующую модель, её оценка появится в блоке «Прогноз нарезки».

## Обязательная настройка номеров столов

Перед нарезкой выберите в **текущем проекте Snapmaker Orca** профиль принтера с комментарием для передачи номера стола. Проверяйте выбранный профиль после открытия каждого 3MF. Проект может подставить свой профиль, даже если ваш профиль Tracker уже сохранён.

Если профиль для Tracker ещё не создан, откройте настройки принтера → «Г-код принтера» → «Г-код начала печати». Добавьте первой строкой этот комментарий и оставьте существующий G-code ниже.

```gcode
; TRACKER_BED_V1 = {plate_number}
```

Сохраните профиль под отдельным именем, например «Snapmaker U1 · Tracker», и выберите его в проекте. Если профиль уже есть, выберите его и заново нарежьте нужные столы. После нарезки сверьте их номера в «Обзор → Прогноз нарезки».

## Проверка прогноза

1. Нарежьте в Snapmaker Orca проект, где порядок материалов отличается от порядка головок, например оранжевый материал 1 назначен на головку 3, а чёрный материал 2 — на головку 1.
2. Откройте «Обзор» или меню Tracker. В прогнозе должны быть цвета и граммы материалов нарезки. Tracker сначала ищет точное совпадение цвета среди катушек подходящего материала. Если точного совпадения нет, он сравнивает цвета визуально. Например, разные оттенки зелёного подходят, если зелёная катушка этого материала одна. При нескольких подходящих катушках «Обзор» показывает варианты. Окончательное назначение головок проверяется при запуске печати.
3. Повторите с несколькими столами и выберите стол в «Обзоре». Сверьте расход каждого стола с Orca. Запуск печати для этой проверки не нужен.
4. Если Tracker просит уточнить головки, проверьте назначения в окне подготовки Orca. При реальном запуске Tracker проверяет расход по карте головок, которую сообщает принтер. Автоматическое списание выполняется только по подтверждённым данным задания.
5. Ручное списание из истории сохранено. После выбора катушки поле «Расход, г» доступно сразу.

Во время печати прогноз для следующей нарезки учитывает ещё не списанный расход
текущего задания по тем же катушкам. В «Обзоре» видно, сколько материала должно
остаться после текущей печати. Пока её расход неизвестен, Tracker показывает,
что запас для следующего задания ещё нельзя проверить.

Windows x64 использует Microsoft Edge WebView2 Runtime. Сборка macOS для Apple Silicon. На принтер ничего устанавливать не требуется.
