Draft release notes — v1.0.1 (do not publish before manual validation)

Snapmaker U1 Spool Tracker checks per-tool G-code filament requirements against four assigned physical spools. This patch release moves inventory to per-user application storage, migrates valid legacy data, protects writes, and reports corrupted data instead of silently resetting it. A missing or invalid usage line now stops export. Warnings on macOS and Windows offer Cancel Export and Proceed Anyway.

Export does not deduct filament. Adjust remaining grams after a real print. A configurable per-tool safety reserve is used for preflight only. The dashboard shows the last result for T0–T3.

macOS: move the unsigned app to /Applications. Windows: keep the exe in a stable folder. Set the app executable as a Snapmaker Orca / OrcaSlicer post-processing script with a trailing semicolon. See README.md, MANUAL_EN.md, and MANUAL_RU.md for exact paths, migration details, and first-run instructions.

Before release: test a real slice, a shortage with Cancel and Proceed, a missing metadata file, existing inventory migration, and the Windows artifact from GitHub Actions. No release is created by CI.
