# Preview 5: вызов окна на передний план

Пользователь подтвердил: в Preview 4 системная строка меню больше не исчезает.
Однако открытая панель могла оставаться за окнами других приложений.

При явном вызове Tracker теперь восстанавливает свёрнутую панель, использует
MoveToActiveSpace и после makeKeyAndOrderFront вызывает orderFrontRegardless.
Последний метод предназначен для вывода окна перед окнами активного приложения,
даже когда приложение-владелец панели не активно.
Политика без Dock, неактивирующая панель и обычный уровень окна сохранены.
Панель не закрепляется постоянно поверх остальных программ.

Удалён последующий безусловный restore на macOS: восстановление выполняется
внутри одного задания главного потока и только для свёрнутого окна.

Пройдены 33 целевых теста. В нативной сборке проверены открытие и повторный вызов
через общий с меню обработчик после переключения приложений. Самопроверка
упакованного приложения и проверка ad-hoc подписи успешны.
Поведение при нескольких перекрывающих окнах и Spaces требует пользовательского
подтверждения. Windows GUI остаётся непроверенным.

Отдельная Preview 5: каталог данных Preview5, порт 8775. Установленный Tracker
и реальные данные предыдущих версий не изменены, реальный U1 не использовался.
