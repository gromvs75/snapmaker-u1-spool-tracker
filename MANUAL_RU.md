# Snapmaker U1 Spool Tracker — руководство пользователя

## 1. Установка

Когда владелец опубликует релиз v1.0.1, скачайте сборку для macOS или Windows. На Mac переместите `SnapmakerSpoolTracker.app` в `/Applications` и запустите. Для неподписанного приложения может потребоваться стандартная команда **Открыть** через контекстное меню. В Windows распакуйте `SnapmakerSpoolTracker.exe` в постоянную папку и запустите. Для нативного окна в Windows требуется Microsoft Edge WebView2 Runtime. Значок появится в строке меню или системном трее. Повторный запуск откроет уже работающую панель.

## 2. Катушки и слоты

Нажмите значок приложения в строке меню или трее и выберите **Настроить катушки и слоты**. Панель откроется в отдельном окне приложения и будет обновляться автоматически. Закрытие окна не завершает фоновое приложение; его можно открыть снова через тот же пункт меню. При первой установке список катушек и все слоты пусты. Добавьте настоящие катушки, укажите материал и фактический остаток в граммах. Назначьте Слот 1 → T0, Слот 2 → T1, Слот 3 → T2, Слот 4 → T3 и сохраните. При удалении катушки её назначение очищается. Начальный вес вводится один раз; исправляйте остаток при взвешивании или если печать не удалось сопоставить. Адрес `http://127.0.0.1:8765` остаётся только для диагностики.

**Страховой запас** добавляется к расходу каждой используемой головки только при проверке. Из остатка он не вычитается. Начальное значение — 0 г.

## 3. Подключение Snapmaker Orca / OrcaSlicer

В **Параметры процесса → Прочее → Скрипты постобработки** укажите путь к исполняемому файлу с точкой с запятой в конце и сохраните профиль:

```text
/Applications/SnapmakerSpoolTracker.app/Contents/MacOS/SnapmakerSpoolTracker;
```

```text
C:\Tools\SnapmakerSpoolTracker\SnapmakerSpoolTracker.exe;
```

Путь Windows замените на фактический. Путь с пробелами заключите в кавычки. Для запуска из исходников на Mac используйте абсолютный путь к `run_hook.sh;` после установки зависимостей в `venv`.

## 4. Подключение U1 для автоматического учёта

В разделе **Монитор принтера U1** укажите имя или IP принтера (по умолчанию `U1.local`) и порт Moonraker (по умолчанию `7125`). Нажмите **Проверить соединение**, включите автоматический учёт и сохраните. Панель покажет наличие соединения и текущее состояние принтера. Оставляйте приложение в трее запущенным. Используется штатный локальный API Moonraker; менять прошивку и создавать учётную запись не нужно.

После краткого отключения или перезапуска приложение может обработать завершённые задания из истории Moonraker. Проверка G-code работает и без связи с принтером. Если файл на принтере был удалён или изменён до сверки либо совпадающие планы имеют разные назначения катушек или расход, автоматического списания не будет: проверьте и исправьте остаток вручную.

## 5. Проверка перед экспортом

Программа читает расход по T0–T3 из G-code и сравнивает его с назначенными катушками. Если материала хватает, экспорт продолжается без окна. В панели виден последний результат: катушка, требуемый расход, остаток и статус каждой головки.

Если используемая головка осталась без катушки или материала мало, выберите **Отменить экспорт** либо осознанно **Продолжить**. Если файл не читается или в нём нет корректных данных о расходе по головкам, экспорт отменяется с ошибкой. Программа не изменяет и не удаляет G-code.

**Экспорт и загрузка не списывают филамент.** После разрешённой проверки сохраняется план: имя и хеш файла, расход T0–T3 и назначенные катушки. Только успешное завершение печати совпадающего файла списывает расчётный расход с сохранённых катушек, причём ровно один раз. Пять повторных экспортов не меняют остаток до фактической печати. Отмена и ошибка печати не списывают полный плановый расход. Расход берётся из оценки слайсера; при расхождении с фактическим весом скорректируйте остаток.

## 6. Данные и восстановление

macOS: `~/Library/Application Support/SnapmakerSpoolTracker/`
Windows: `%LOCALAPPDATA%\SnapmakerSpoolTracker\`

При первом запуске старая корректная `spools_u1.json` рядом с прежним приложением или скриптом копируется в новую папку. Исходный файл сохраняется. Повреждённая база не заменяется молча: приложение сохраняет оригинал, создаёт копию в `backups/` и показывает ошибку. Для диагностики используйте `tracker.log` в той же папке. Восстановите заведомо исправную копию перед продолжением.

Перед долгой печатью проверьте интеграцию на небольшом реальном G-code и намеренно недостаточном остатке. Программа сверяет учётные данные и не определяет физическую подачу пластика или несовпадение материала.
