## Snapmaker Forum — English

**Spool Tracker 1.2.1 — for the original U1 firmware, with a quieter Mac workflow**

**First, an important clarification: Tracker is designed to work with the original (stock) Snapmaker U1 firmware. No custom firmware, flashing, or additional components on the printer are required. The application runs on your computer.**

I've released 1.2.1 with a more convenient way to see the result after slicing in Snorca.

On macOS:

- The main Tracker window no longer pops up after slicing.
- The menu opens automatically from the menu bar, with no Dock icon.
- Green checks and red crosses show whether the assigned spools have enough filament, including the reserve. Each used head shows the estimated amount left after printing or the shortage; unused heads remain neutral.
- The menu identifies the latest completed plate and its timestamp. Changing a balance updates the result without reopening the menu.
- Clicking the forecast opens the full Overview when needed.

The new menu text is translated into English, Russian, German, Ukrainian and Spanish. Windows updates its tray icon and menu, but automatic menu opening is currently macOS-only.

**Downloads:** https://github.com/gromvs75/snapmaker-u1-spool-tracker/releases/tag/v1.2.1

The release includes macOS Apple Silicon arm64 and Windows x64 packages, SHA256 checksums and build information. **Windows GUI and real Snorca slicing on Windows are still unverified.** Passing automated tests and the executable self-test does not replace that desktop check.

The update keeps the existing 1.2 beta inventory; back up before replacing the app. Menu Test inventories aren't imported automatically. No modified printer firmware is required, and this update doesn't add RFID or Spoolman integration.

The usual forecast limits remain: consumption is a slicer estimate, material 1→T0 … 4→T3 is an assumed mapping, and the result applies to one completed plate. Slicing/reslicing doesn't reserve or deduct filament and doesn't start a print.

Thanks for the feedback so far. Feel free to share your impressions of the new menu behavior.
