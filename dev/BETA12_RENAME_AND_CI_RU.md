# Tracker 1.2 beta — переименование и проверка сборок

Исторический протокол сборок до добавления документации в PR.

Дата: 2026-11-04. Код сборки: `83be812a316ae3711a557c8ea9d0793d92c757d3`, ветка `v1.2-beta-integration-build`.

Публичное название приложения — **1.2 beta**, имена новых пакетов содержат `1.2-beta`. Будущий тег может быть `v1.2.0-beta`; тег и релиз не созданы. Внутренний bundle ID сохранён, чтобы переименование не создавало новую идентичность beta-приложения; номер Mac-сборки — 2.

## Причина красных macOS-запусков

Запуски 41881363127 и 41881367475 не получили hosted runner. GitHub сообщил: “The job was not acquired by Runner of type hosted even after multiple attempts” и отдельно указал нехватку arm64 runner. Ни один шаг тестирования или упаковки в этих заданиях не выполнялся. Исправлять код приложения из-за этих двух запусков не требовалось.

В оба workflow добавлено ограничение одновременных запусков одной ветки. Оно убирает дублирующие задания, но не гарантирует доступность runner. Архитектура Mac не подменялась на Intel.

Установленный Tracker, реальный U1 и пользовательские настройки не затрагивались. В CI-ветку отправлены изменения исходников и workflow; документация, Reddit и Snapmaker Forum остаются локальными черновиками. Main не изменён, релиз не опубликован.
