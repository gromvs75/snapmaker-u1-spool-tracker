# Snapmaker U1 Spool Tracker 2.1.1 beta

## What changed

- **macOS Apple Silicon**. Tracker reads the selected toolheads in **Print Preprocessing** in Snapmaker Orca 2.4.1. Changing an assignment moves the estimate to the selected spool before the print starts, even if the colors differ. For a mix such as Orca material #5, the estimate follows each physical component. The menu opens when an assignment changes while Orca is in front.
- **Windows x64 and macOS**. Preliminary estimates after slicing now tolerate nearby shades of the same color. Tracker asks you to check assignments when more than one spool fits. During a print, the estimates and accounting follow the physical mapping verified by the U1.
- **macOS upgrades**. If Tracker lacks permission to read Orca, it shows a reminder in the forecast and menu. An enabled switch can still belong to the signature of a previous beta. Remove that permission entry and re-add the installed copy under Privacy & Security. The setup guide shows the panel names for different macOS versions.

## Included from 2.1.0 beta

You can start a print from **Snapmaker Space** on your phone with Orca closed. Connect Tracker to the U1 before you start, and keep Tracker running and connected and the computer awake until the job finishes. Once Tracker can verify the file and toolhead mapping, the used cards show the G-code estimate and remaining balance after the job. Check History afterward for recorded usage or a review request. Manual spool assignments and print accounting use the factory Snapmaker U1 firmware.

## Installation and validation

Download the ZIP for your system and quit any previous Tracker instance before updating. Windows uses WebView2 and needs the `_internal` folder from the archive. The Mac app uses an ad-hoc signature. Use the same permanent app path for your Orca preset and any accessibility permission. The 2.1 beta continues to use its existing data folder.

The live remap forecast and auto-opening menu were verified on a Mac with Snapmaker Orca 2.4.1 and a real U1. The Mac archive was built and tested locally with the simulator from the release commit. The Windows archive was built and tested in WebView2 with the simulator in GitHub Actions. A physical U1 test on Windows is pending. The live **Print Preprocessing** forecast and popup are macOS features in this beta.
