# Tracker 2.0.0rc21 — тестовая сборка

## Windows

1. Полностью распакуйте ZIP в отдельную папку, например «Tracker 2.0 тест».
2. Запустите `Snapmaker-Tracker-2.0-Candidate.exe` двойным щелчком.
   Папку `_internal` оставьте рядом с EXE. Устанавливать Python или запускать
   команды не нужно. Для окна используется Microsoft Edge WebView2 Runtime.
3. Не заменяйте файлы старой версии. Новая сборка хранит данные отдельно от 1.3.3.

## Mac

Распакуйте ZIP и запускайте `Snapmaker-Tracker-2.0-Candidate.app`.
Сборка предназначена для Apple Silicon. Она использует профиль кандидата 2.0;
перед заменой rc20 сохраните резервную копию и завершите rc20 через меню трея.
Старую `.app` можно оставить в отдельной папке для возврата.

## Первый запуск и проверка

Сначала сохраните резервную копию в прежнем Tracker. Проверку новой версии
начните между печатями: завершите старый Tracker, чтобы две версии одновременно
не списывали расход одной печати в Spoolman.

В новой версии восстановите копию через настройки либо настройте отдельный
профиль. Проверьте остатки и назначения катушек на T0–T3. Катушку можно выбрать
по ID Spoolman; RFID для учёта не нужен. На принтер ничего устанавливать не надо.
Старые пропуски после импорта автоматически не списываются повторно.

Подключение к принтеру запускается вручную. После восстановления копии отправка
в Spoolman выключена: для первой проверки можно оставить режим чтения и
сравнить локальный остаток. Если нужен расход в Spoolman, включите отправку
отдельно, убедившись, что старый Tracker завершён.

Напечатайте обычную небольшую модель. После завершения проверьте расход и
остаток, затем обновите историю и перезапустите Tracker: второй раз та же печать
списываться не должна. Крестик скрывает окно; полностью завершить приложение
можно пунктом «Выход» в меню значка Tracker.

Если снова увидите «расход не учтён», сохраните резервную копию и логи сразу,
пока они не заменились новыми. Укажите имя модели, время, головку и ID катушки;
скриншот тоже поможет. Не исправляйте остаток до сохранения копии.

Журналы Windows: `%LOCALAPPDATA%\Snapmaker Tracker 2.0\logs`.
Журналы Mac: `~/Library/Application Support/Snapmaker Tracker 2.0/logs`.
Сборка сама ничего не отправляет разработчику.

Это кандидат для проверки. При потере наблюдения во время печати или
неподтверждённой смене катушки расход может потребовать сверки.
