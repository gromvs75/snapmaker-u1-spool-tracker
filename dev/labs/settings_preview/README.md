# Изолированный предпросмотр настроек

Статический интерактивный макет для обсуждения интерфейса. Не является сборкой Tracker.

Запуск из этого checkout:

```sh
python3 dev/labs/settings_preview/serve.py
```

Открыть напечатанный локальный адрес. Сервер обслуживает только HTML и JavaScript стенда.

- Разделы: Принтер, Spoolman, Учёт, Резервная копия.
- Spoolman: подключение, цветные катушки с поиском, передача расхода.
- Выбор катушки показывает её данные и одинаковые по ширине кнопки справа.
- Назначение и отвязка работают только в памяти страницы. Перезагрузка сбрасывает изменения.
- Все катушки, адреса, остатки и статусы демонстрационные.
- Нет подключения к Tracker, Spoolman или принтеру, нет чтения пользовательской базы, сохранения настроек и списания расхода.
- CSP запрещает сетевые подключения из страницы. Внешних ресурсов нет.
- Проверка названия показывает пример совпадения; пакетная синхронизация здесь не реализована.

Основа компоновки: согласованный вариант Three-Pane из отчёта
https://www.lazyweb.com/report/lazyweb/2c8fe11a-efd6-4783-87b3-9dc3a864598e/?source=create
с уточнениями пользователя: только разделы Tracker, цветные катушки, кнопки столбцом справа.

Проверено в браузере: восемь катушек; поиск; пустая выдача; назначение с отменой и подтверждением; отвязка с сохранением остатка; переключение разделов; клавиатурная навигация вкладок; одинаковые координаты и ширина кнопок; отсутствие горизонтального переполнения при ширине 390 px; отсутствие ошибок консоли. Windows GUI не проверялся, исполняемые сборки не создавались.

Ветка: ui/settings-preview. С 2.0.0 не объединять без отдельного решения после просмотра.
