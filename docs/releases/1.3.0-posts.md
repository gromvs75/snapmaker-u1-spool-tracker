## Reddit

**Title:** Snapmaker U1 Spool Tracker 1.3.0: Spoolman integration on stock firmware

I've released version 1.3.0 of Snapmaker U1 Spool Tracker.

**Spool tracking and usage forecasts for Snapmaker U1 — without firmware changes.** Spoolman connects through Tracker; no components need to be installed on the printer. The U1 stays on its original firmware.

What's new:

- Browse Spoolman's spool catalog and balances, and assign physical spools to T0–T3.
- Start in read-only mode. Slicing in Snorca shows a usage forecast and does not deduct filament.
- Optionally enable consumption delivery after registered, matched, successfully completed prints. Tracker sends the usage to Spoolman, with no second local deduction for those spools.
- Duplicate-event protection and a persistent delivery queue. If a write response is lost, delivery pauses for manual review instead of automatically retrying an ambiguous deduction.
- macOS menu/window fixes and detailed setup guides.

Spoolman is installed separately; the integration supports 0.27.1. It also remains possible to use Tracker with local spools alone. Before upgrading, export a Tracker backup and close any other instance accounting for the same printer.

Testing covered a real local Spoolman server with artificial spools and a U1 simulator, including outages, multi-color usage, head permutations and backup restoration. **Real U1 printing with Spoolman and sustained operation still need user validation. Windows GUI and real Snorca slicing on Windows remain unverified**, although the Windows CI and packaged self-test passed. The Mac build is for Apple Silicon, ad-hoc signed and not notarized.

## Snapmaker Forum

**Title:** U1 Spool Tracker 1.3.0 — Spoolman integration without changing the printer firmware

Version 1.3.0 adds optional Spoolman integration to Snapmaker U1 Spool Tracker.

**Spool tracking and usage forecasts for Snapmaker U1 — without firmware changes.**
**Connects through Tracker. No components need to be installed on the printer.**

The printer continues to run its original U1 firmware. Snorca provides the sliced print data; Tracker associates a registered print plan with the printer's observed print and submits consumption after a matching successful completion. Spoolman stores the external spool catalog and balances.

You can begin with catalog reading only, assign Spoolman spools to T0–T3 and inspect the forecast after slicing. Slicing never deducts filament. Usage delivery is a separate opt-in setting and requires confirming that this Tracker is the sole sender for that U1.

The integration keeps a persistent delivery queue and protects against repeated print events. A lost write response is marked uncertain and requires review; it is not blindly retried. Restoring a Tracker backup disables the Spoolman integration and marks unfinished deliveries uncertain. The backup does not roll back balances in Spoolman.

The release also retains the macOS menu-bar fixes: slicing opens the result menu without opening the dashboard, and the requested dashboard can be brought forward without losing the system menu bar.

Supported server: Spoolman 0.27.1, installed separately. Forecasts remain estimates, and the pre-print material-to-head mapping is visibly marked as assumed. Successful accounting requires a registered, matched plan and verified mapping. Start with read-only mode and read the guide before enabling sending.

Validation used artificial spools, a local Spoolman server and a U1 simulator, covering multi-color consumption, all 24 head permutations, connection loss, duplicate events and backup restoration. Real U1 printing with Spoolman and sustained operation still require user validation. **Windows GUI and real Snorca slicing on Windows remain unverified.** Automated Windows tests and the packaged self-test passed. macOS targets Apple Silicon and is ad-hoc signed, not notarized.

Export a JSON backup before upgrading. Version 1.3.0 keeps the 1.2.1 inventory directory; Preview data is not imported automatically. Avoid running two senders for the same printer.
