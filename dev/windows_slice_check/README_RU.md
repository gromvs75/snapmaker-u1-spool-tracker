# Windows / Snorca: комплект для отдельного тестировщика

Статус: подготовлен, но на Windows здесь НЕ запускался. У владельца проекта нет Windows; эта инструкция не требует от него установки Windows или изменения настроек Mac.

## Что подготовлено

В архиве находятся Windows.exe 1.2 beta, искусственная база четырёх катушек, куб 20 мм, конфигурация Windows Sandbox и два скрипта для гостевой системы. Настоящая нарезка должна происходить кнопкой Slice в Snorca, без экспорта/копирования G-code. Предыдущая инструкция с копированием готового G-code не заменяет этот опыт.

Сеть и буфер обмена Sandbox отключены. Внутрь подключается только папка комплекта, только для чтения. Установленные на Windows-хосте Tracker, Snorca и их настройки не подключаются. Гостевой TEMP и --datadir Snorca направлены в отдельный TrackerLab; Tracker использует --isolated-root и наблюдает только гостевой temp/snapmaker_orca_model. Подключение к реальному U1 невозможно при отключённой сети Sandbox.

## Требования к отдельному стенду

Нужен Windows-компьютер с УЖЕ доступной Windows Sandbox. Комплект не устанавливает компоненты Windows и не меняет виртуализацию или сетевые правила хоста. Альтернатива — отдельная Windows VM с отключённым сетевым адаптером и чистым снимком, но данные скрипты предназначены именно для Sandbox.

До запуска Sandbox тестировщик добавляет в папку комплекта официальный Windows-дистрибутив Snorca 2.4.1 и при необходимости офлайн-установщики WebView2/VC++ runtime. Эти сторонние дистрибутивы в архив НЕ включены. Источник Snorca: https://github.com/Snapmaker/OrcaSlicer/releases/tag/v2.4.1 . Ничего не устанавливать на хост ради этого теста: установки выполняются только внутри гостя.

1. Распаковать комплект в C:\TrackerBeta12TestKit либо изменить только HostFolder в Offline.wsb на путь к распакованному комплекту. Запустить Offline.wsb.
2. В госте установить Snorca и необходимые офлайн-зависимости из C:\TestInputs. Не входить в аккаунт, не подключать принтер. Если не удаётся запустить Snorca/WebView2 без сети — зафиксировать блокировку; сеть не включать.
3. В гостевом PowerShell выполнить:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\TestInputs\Start-Guest.ps1 -SnorcaExe "ПОЛНЫЙ ПУТЬ К EXE SNORCA В ГОСТЕ"
```

ExecutionPolicy здесь задан только для гостевого процесса, политика хоста не меняется. В мастере Snorca выбрать встроенный профиль U1 и PLA офлайн. Куб уже передан программе. При отсутствии профиля зафиксировать блокировку, не импортировать личные настройки.

## Короткая проверка (для Windows-тестировщика)

1. **Slice plate:** скрыть Tracker в трей, нарезать куб. Tracker должен сам появиться, показать расход T0 и зелёный ✓. Остаток на тестовой катушке остаётся 100 г.
2. **Повторная нарезка:** скрыть Tracker, увеличить куб или изменить слой, снова Slice. Окно появляется повторно, расход обновляется, остаток всё ещё 100 г.
3. **Две пластины:** добавить вторую пластину с другим размером куба, Slice all. В Tracker доступны две пластины с разными прогнозами. Не требовать ровно одного автопоказа: пластины могут завершаться отдельными пачками.
4. **Нехватка:** только в тестовом Tracker задать T0=0 г. Должен появиться красный ✕ с дефицитом и резервом. Затем вернуть 100 г.
5. **Перезапуск:** завершить обе программы, повторить запуск скрипта, открыть новый тестовый проект и Slice. Прогноз должен обнаружиться снова. База гостя сохраняется между перезапусками приложений, но удаляется при закрытии Sandbox.

Проверку отмены нарезки не усложняем: прогноз относится к последней завершённой нарезке.

После этапов 1–3 запустить внутри гостя:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\TestInputs\Capture-Guest.ps1
```

Записать результат каждого пункта и сфотографировать окно/сводку до закрытия Sandbox. verification.json остаётся внутри гостя: папка хоста намеренно read-only, автоматического вывода данных из песочницы нет. Не сообщать об успехе только на основании роста auto_shows: фактическое появление окна проверяется глазами.

## Критерий результата

Windows GUI подтверждён только если завершённая НОВАЯ нарезка в Snorca автоматически обнаружена, правильная пластина/расход показаны, скрытое окно действительно появилось, списаний нет. CI/self-test EXE и проверка XML/скриптов на Mac этого не подтверждают.

Изоляция Windows Sandbox: https://learn.microsoft.com/windows/security/application-security/application-isolation/windows-sandbox/windows-sandbox-configure-using-wsb-file
