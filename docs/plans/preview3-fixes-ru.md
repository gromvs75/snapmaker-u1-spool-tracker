# Проверка Preview 3

Исправлен дефект индикации: результат разовой проверки соединения раньше
перезаписывался фоновым статусом выключенного монитора. Теперь результат
показывается отдельно, а выключенный монитор обозначен как «Автоматический учёт
выключен». Изменение адреса очищает результат предыдущей проверки.

## Первый запуск без backup

1. Введите адрес U1 и порт 7125.
2. Нажмите «Проверить соединение». Это не включает автоматический учёт.
3. Нажмите «Сохранить настройки принтера», чтобы сохранить адрес.
4. Учёт включайте отдельно после назначения катушек, когда другой Tracker
   не ведёт учёт этого U1. Для первого теста чтения Spoolman оставьте его выключенным.

На стенде с пустой базой проверены ручной ввод адреса симулятора, подключение
без импорта и сохранение настроек. Результат не исчезает при обновлении статуса.
Реальный U1 не использовался; это не доказывает причину любого сетевого сбоя.

## Строка меню macOS

Добавлено восстановление скрытой строки меню при активации приложения,
получении фокуса окном и смене рабочего стола. Обработка выполняется только
для активного приложения с видимым обычным окном. Полноэкранные окна,
системные настройки и политика скрытия значка Dock не меняются.

Нативная Preview 3 запущена; после Control-Right/Left меню было доступно
и открылось. Исходное исчезновение в точности не воспроизведено, поэтому
исправление требует проверки в обычном сценарии пользователя.

Пройдены 35 целевых тестов, самопроверка готовой сборки и проверка ad-hoc подписи.
Сборка не нотариализована. Windows GUI остаётся непроверенным.
Данные Preview 3 отдельные, порт интерфейса 8773. Установленный Tracker не заменён.
